# 🐾 Happy Tails - Animal Shelter Website

A warm and welcoming animal shelter website dedicated to helping cats and dogs find their forever homes.

The project aims to connect animals in need with loving families by creating an engaging and user-friendly adoption experience.

## 🌐 Live Demo

[Visit the website](https://petsshelter.vercel.app/)

## ✨ Features

- 🐶 **Animal Adoption** — a platform for discovering cats and dogs looking for a home.
- 🐱 **Animal Profiles** — dedicated sections to showcase animals and their stories.
- 💛 **Adoption-Focused Design** — an emotional and welcoming interface that encourages adoption.
- 📱 **Responsive Design** — an interface designed for different screen sizes.
- 🎨 **Modern UI** — a clean and visually appealing design with a focus on usability.
- 🏡 **Forever Home Mission** — helping animals find caring and responsible families.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd petsshelter
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local development URL in your browser.
